# Good Bias

A gown cut from four straight strips that fits many body sizes, because the cloth itself does the fitting. Three cuts dress sizes 34 to 54, with no offcut and no stretch fibre.

It rests on a law I proved for how far woven cloth can move around any body:

widest girth / narrowest girth ≤ tan(45° + γ/2)

where γ is how far the cloth shears before it locks. Only the true bias reaches this limit.
